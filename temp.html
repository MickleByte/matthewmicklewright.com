I created erewashrag.com as a fun project to 1. annoy my friend who is a Borough Councillor and 2. try out some new technologies. The UI is built using React and calls a RESTful API to retrieve articles from an API.

On the backend, I used a Python AWS Lambda and API Gateway to expose the API. The Lambda function then does CRUD operations on DynamoDB.

The whole infrastructure is created using a CloudFormation template and deployed using GitHub Actions.
