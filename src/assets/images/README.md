# Portfolio Images

Place your project images in this directory.

## Supported Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.svg`

## Usage

After adding an image, import it in `src/data/projects.js`:

```javascript
import myProjectImage from '../assets/images/my-project.jpg'

export const projects = [
  {
    // ...
    image: myProjectImage,
    // ...
  }
]
```
