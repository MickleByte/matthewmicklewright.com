# Project Overview

I'm a volunteer in Scouts in my local town Long Eaton and in 2020 I was asked to creat this website to provide basic information on Scouting in the area and how to join. 

I built the site using plain HTML and CSS and deployed it to an existing server using FTP. It's since been superseded as Long Eaton Scouts merged with Ilkeston in 2024 to form Erewash Scouts, but you can still view my dev version of the website [on GitHub Pages](https://micklebyte.github.io/longEatonDistrictSite/)
