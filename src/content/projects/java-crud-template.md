# The Project Overview

This was a quick project mainly for my own benefit to create a template repo that I could repurpose when wanting to quickly spin up CRUD APIs. I tried to focus on quick testability locally and included a docker configuration to allow spinning up of Tomcat, MySQL DB and Flyway containers.

[Github Repository](https://github.com/MickleByte/java-crud-template)
