# Project Overview

Write the project up in normal markdown — headings, lists, links, code blocks
and images are all styled by the project layout.

Images live next to this file and are referenced relatively, so Astro optimises
them and the build fails if a path is wrong:

Add `"left"` or `"right"` after the path to float an image so the text that
follows wraps around it (it goes full width on narrow screens):

## How to add a project

1. Copy this folder to `src/content/projects/<slug>/` — the folder name becomes
   the URL, e.g. `/projects/<slug>`.
2. Drop the images into that folder next to `index.md`.
3. Fill in the frontmatter above and write the body.
